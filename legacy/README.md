# 原始单文件版本

`index.original.html` 是重构前的完整游戏：HTML、CSS、噪声、世界生成、玩家、渲染与 UI 全部内联在一个文件里，Three.js 通过 jsDelivr CDN 动态导入。

保留它是为了：

- 对照重构前后的视觉与数值行为；
- 在需要时逐段核对原始参数和随机数消耗顺序；
- 避免工程化过程中丢失任何玩法细节。

该文件**不参与** Vite 构建，也不会出现在 `dist/` 中。开发服务器启动后，可以通过下面的地址临时打开它做对照（需要能访问 CDN）：

```text
http://127.0.0.1:5173/legacy/index.original.html
```
